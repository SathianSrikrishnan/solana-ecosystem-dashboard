# Solana Observatory — three-minute demo

Status: awaiting Sathian's approval before recording

## 0:00–0:29 — Overview

Browser cue: hold on the hero, source-health card, and six-question map.

> Most ecosystem dashboards give you more numbers. I built Solana Observatory
> because I wanted a simpler way to ask six questions: is the network working,
> are people and applications returning, is useful economic activity growing,
> is the validator set resilient, is the ecosystem compounding, and is Solana
> becoming financial infrastructure? Right now, 36 measurements are live. Nine
> gaps are visible rather than quietly removed.

## 0:29–0:47 — Network

Browser cue: select Network and point across the first row of evidence cards.

> The network view begins with the basics: block and slot progress, non-vote
> throughput, estimated slot time, and RPC health. Each card carries its
> definition, source, collection time, confidence, and limitation, so the
> headline number is never separated from the evidence.

## 0:47–1:08 — Adoption

Browser cue: select Adoption and hold on the stale status and trend cards.

> Adoption is where the dashboard is deliberately cautious. Wallet addresses
> are not treated as people. Five Dune measurements are currently stale, which
> means the last verified values are preserved and dated. They are not
> presented as fresh, and they are not replaced with zeros.

## 1:08–1:30 — Economy

Browser cue: select Economy and point across fees, revenue, and the trend cards.

> The economy view separates things that are often collapsed: application
> fees, application revenue, chain fees, total value locked, DEX volume, and
> REV. The comparison is the latest seven complete days against the seven
> before that. Direction is visible, but the dashboard does not call every
> increase good.

## 1:30–1:50 — Validators

Browser cue: select Validators and hold on concentration and validator depth.

> Resilience is not just an uptime question. This section tracks active stake,
> delinquency, commission, the superminority coefficient, and concentration
> among the largest vote accounts. It shows the structure of the validator set
> without pretending that a vote account always equals one operator.

## 1:50–2:04 — Ecosystem

Browser cue: select Ecosystem and point to release cadence and Alpenglow.

> Ecosystem change is tracked through the Agave release cadence, official
> Solana news, and upgrade milestones. Alpenglow is shown as in development for
> Q3 2026, directly from Solana's official roadmap.

## 2:04–2:22 — Financial rails

Browser cue: select Financial rails and hold on stablecoins and the visible gaps.

> Financial rails asks what is actually emerging beyond trading. Stablecoin
> circulation is measured live. Identifiable payments and tokenized real-world
> assets remain unavailable until there is a defensible source and attribution
> method. The gap is part of the report.

## 2:22–2:39 — Methods

Browser cue: select Methods and point to the three public proof formats.

> Every output comes from one validated snapshot, published as interactive
> HTML, readable Markdown, and machine-readable JSON. The workflow refreshes
> automatically, runs deterministic tests, and keeps an optional source
> failure visible instead of blanking the whole dashboard.

## 2:39–3:00 — Close

Browser cue: return to Overview and hold on the hero and six-question map.

> I built this as a way for a newcomer to examine Solana without pretending
> one metric settles the argument. The dashboard is live, the code and sources
> are public, and the limitations stay attached to the numbers. That gives us
> a better place to start asking questions.
