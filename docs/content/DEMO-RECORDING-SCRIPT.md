# Solana Observatory demo recording

Target: 70–80 seconds. Record the live dashboard at 1080p with the browser at
100% zoom. Move the cursor slowly and pause briefly after each click.

## Spoken script and screen direction

**0–10 seconds — Start Here**

> Most crypto dashboards show activity without explaining what it means.
> Solana Observatory asks six clearer questions about the network, adoption,
> economy, validators, ecosystem, and financial rails.

Show the title, source-health summary, and the thirty-second Start Here path.

**10–24 seconds — Six-question map and automatic briefing**

> These six questions connect the system without collapsing it into one health
> score. The report refreshes every six hours, and every explanation points back
> to the measurements that support it.

Pause over the six-question map and automatic evidence briefing.

**24–40 seconds — Economy**

> In the economy layer, application fees, application revenue, chain fees, and
> REV stay separate. That prevents similar-sounding numbers from telling a
> misleading story.

Scroll to Economy and point to those four cards.

**40–54 seconds — Evidence**

> Every card includes its definition, collection time, source, confidence, and
> limitation. Missing evidence remains visible instead of being silently filled
> with an estimate.

Open one evidence drawer, then close it.

**54–66 seconds — Financial rails**

> The financial-rails layer is deliberately strict: stablecoin transfers are
> not automatically called payments, and tokenized-asset gaps are labeled until
> a reproducible source is available.

Scroll to Financial Rails and pause on the documented gaps.

**66–78 seconds — Close**

> The same verified snapshot publishes as interactive HTML, readable Markdown,
> and machine-readable JSON. This is Solana Observatory: a living instrument
> panel for understanding the network without hiding the uncertainty.

Return to the overview and end on the dashboard title and live URL.

## Recording checklist

- Hide bookmarks, notifications, wallet extensions, and personal tabs.
- Use the public URL, not a local file.
- Keep the recording under 90 seconds.
- Export MP4 at 1080p; confirm narration is audible before uploading.
- Do not show the Dune key, GitHub settings, terminal, or account information.
